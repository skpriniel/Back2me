# Reflection Journal 

## Week of: September 16 to September 23, 2026

## My goal this week

My goal this week was to finalize the Back2me proposal, decide how the app would store its data, and start preparing the design and documentation for the final project.

## What I did

I revised my Back2me proposal based on my professor's feedback by updating the MVP features, data models, storage method, and technical risks. I decided to use Hive for local data storage and wrote down what data each model needs to store.

I also worked on the Back2me mockup in Canva. I designed the Login, Home, Item Details, Lending Records/History, and Add Lending Record screens. I added details such as the search bar, status tiles, lending information, return reminders, borrower contact options, and due-date options. I also compared the mockup with the design system and listed the components that needed to be changed or added.

For the project documentation, I started filling in the Features and Usage, Project Structure, README, Weekly Increment Report, and Reflection Journal sections based on the work I had done.

## What blocked me

I had difficulty making sure that the proposal, mockup, and documentation matched because some of the screens and features changed while I was working on the project. I also had to clarify which features should be included in the MVP and which ones should remain as stretch goals.

## What I learned

I learned that I need to keep the proposal, design, and documentation consistent when making changes to the project. I also learned more about how Hive can be used as the planned local storage for Back2me and what information needs to be stored for the different records.
