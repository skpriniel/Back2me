# Reflection Journal 

## Week of: September 23 to September 27, 2026

## My goal this week

My goal this week was to continue developing the Back2me project by improving the mockup, organizing the project structure, and updating the documentation based on the current features and planned implementation.

## What I did

I continued working on the Back2me documentation by completing the Overview, Setup and Installation, How to Run It, Features and Usage, and Project Structure sections. I also added the screenshots section and documented the known issues and next steps for the project.

I described the purpose of each screen, including the Login, Home, Item Details, Lending Records, and Add Lending Record screens. I also explained the primary flow of the app, from signing in and creating a lending record to monitoring the item's status and marking it as returned.

I documented the planned use of Hive for local data storage and listed the remaining tasks, such as implementing CRUD operations, connecting items and borrowers to lending records, and testing data persistence. I also identified some features that would remain stretch goals so I could focus on completing the core MVP first.

## What blocked me

One challenge was making sure that the documentation accurately reflected the current design and planned functionality of Back2me. Some features, such as reminders, direct borrower contact, and filtering, still need to be clarified or implemented. I also have not completed all the screenshots for the app, so the documentation is still a work in progress.

## What I learned

I learned that documentation should reflect what the app actually does and not just what I plan to implement. I also realized that I need to prioritize the core features before adding extra functionality. Moving forward, I need to focus on implementing the main lending workflow, ensuring that item and lending statuses stay consistent, and testing whether the data is saved properly even after closing and reopening the app.
